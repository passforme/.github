# passforme/.github

The organization's profile page, and nothing else: GitHub renders
`profile/README.md` at https://github.com/passforme. English only,
Conventional Commits, signed, no AI attribution, as in every passforme
repository.

The page repeats three things from the main repository's `README.md`,
and must say the same as it: the tagline under the logo, the one-line
install, and the security address. When one of them changes there, it
changes here in the commit that follows. The logos come from
`passforme.com/brand/logo/`, the brand kit's own address, never from a
copy.
